# Full Circle Racing Website

This package is built to match the latest approved Full Circle Racing website mockup.

## Upload to GitHub

Upload these items to the ROOT of your existing `full-circle-racing-website` repository:

- `index.html`
- `style.css`
- `config.js`
- `script.js`
- `CNAME`
- the complete `assets` folder

`index.html` must be visible immediately when you open the repository. Do not place these files inside another folder.

## Custom domain

The included `CNAME` contains:

`fullcircleracing.net`

If your existing repository already has a working CNAME file, keeping that existing file is also fine.

## Easy edits

Open `config.js`.

You can change:
- YouTube / Instagram / Twitch / Discord URLs
- featured-video URL
- every major heading
- homepage description
- About text
- race schedule
- featured gear names

## Images

The images in `assets` were taken directly from the approved website mockup so the live website stays visually close to it.

- `fcr-logo.png`
- `hero-car.jpg`
- `youtube-feature.jpg`
- `rig-setup.jpg`
- `approved-reference.jpg`

The approved reference image is included only so future website changes can be compared with the intended design.

## Important

GitHub Pages should automatically redeploy after you commit the files.

Your Namecheap DNS does not need to be changed again.
