# Full Circle Racing Website — Version 3

This version follows the approved dark red/black motorsport layout and is ready for GitHub Pages.

## Upload these to your GitHub repository

- `index.html`
- `style.css`
- `config.js`
- `script.js`
- `assets/hero-car.png`
- `assets/rig-setup.png`

You may keep your existing `CNAME` file if GitHub created one for `fullcircleracing.net`.

## Easiest edits

Open `config.js` to change:

- YouTube / Instagram / Twitch / Discord links
- featured video link and title
- About text
- rig equipment
- upcoming race schedule

## Important

Do not delete the `assets` folder. The website uses the images inside it.
